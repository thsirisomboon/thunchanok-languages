Create a beautiful, polished homepage for a personal multilingual language-learning knowledge system called **“THUNCHANOK LANGUAGES”**.

The website is a personal long-term language-learning dashboard for studying **Spanish, French, and Korean**, organised systematically from **CEFR A1 to C2**.

## 1. Overall Design Direction

Create a visual style that is:

- Soft pastel
- Cute but sophisticated
- Clean and academic
- Calm and elegant
- Minimal but not empty
- Friendly and motivating
- Suitable for a serious adult learner
- Inspired by a modern digital study notebook / personal knowledge management system
- Visually consistent with an academic research dashboard, but warmer and more charming

Avoid:
- childish cartoon aesthetics
- overly bright colors
- neon colors
- excessive decorations
- overly corporate appearance
- dark heavy backgrounds
- complicated animations
- cluttered layouts

The design should feel like:

**“A beautiful personal language library that I would genuinely want to open and study every day.”**

---

# 5. CEFR LEARNING PATH

Create a visual horizontal progression:

**A1 → A2 → B1 → B2 → C1 → C2**

Each level should be displayed as a small rounded card.

### A1
**Foundation**

Basic vocabulary, pronunciation, greetings, introductions, and survival communication.

### A2
**Everyday Communication**

Daily routines, common situations, simple conversations, and practical language.

### B1
**Independent User**

Narration, explanations, opinions, experiences, and connected speech.

### B2
**Confident Communication**

Discussion, argumentation, abstract topics, and more sophisticated grammar.

### C1
**Advanced / Professional**

Academic, professional, nuanced, idiomatic, and context-sensitive language.

### C2
**Mastery**

Precision, subtle meaning, register, idiomatic expression, and sophisticated discourse.

The progression should visually communicate:

**Foundation → Independence → Advanced → Mastery**

# 11. UI / UX REQUIREMENTS

The homepage must be:

- fully responsive
- desktop-friendly
- tablet-friendly
- mobile-friendly
- easy to navigate
- accessible
- fast-loading
- visually uncluttered

Use:

- rounded corners
- generous whitespace
- subtle borders
- soft shadows
- clean typography

---

# 12. TYPOGRAPHY

Use a clean modern sans-serif typeface.

Headings should be:

- elegant
- slightly bold
- highly readable

Body text should be:

- comfortable for long reading
- medium contrast
- dark gray rather than pure black

Use typography hierarchy clearly:

**H1 → H2 → H3 → body → metadata**

---

# 13. VISUAL PERSONALITY

The final design should combine:

**Pastel Blue + Cream + White + Dark Gray**

with:

**Academic + Calm + Cute + Intelligent + Personal**

The website should feel like a combination of:

- a personal study journal
- a modern language-learning dashboard
- a digital library
- a beautiful Obsidian knowledge system

The design should remain mature enough for an adult learner pursuing advanced academic and professional language proficiency.

---

# 14. IMPORTANT CONTENT PRINCIPLE

Do not overcrowd the homepage with individual lessons.

The homepage is the **overview / command center**.

Individual lessons will live inside:

**Spanish → A1–C2**

**French → A1–C2**

**Korean → A1–C2**

The homepage should therefore prioritize:

**orientation → navigation → learning philosophy → progress structure**

rather than displaying every lesson.

---

# 15. FINAL DESIGN GOAL

The final page should immediately communicate:

> **“This is my personal multilingual learning system.”**

A visitor should understand within a few seconds:

1. What languages are being studied.
2. That each language follows CEFR A1–C2.
3. How the learning system works.
4. Where to enter each language.
5. That the system is designed for long-term mastery.

Make the result polished, cohesive, elegant, soft, cute, and highly usable.
